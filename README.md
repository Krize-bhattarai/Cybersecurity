## Technical Competencies & Toolsets Mastered

### 1. SIEM Log Forensics & Alert Triage
* **Tools:** Splunk, ELK Stack.
* **Skills:** Engineered search queries to parse raw system telemetry, map event correlation timelines, and isolate anomalous behaviors during active security incident triage.

### 2. Network Traffic & Telemetry Analysis
* **Tools:** Wireshark, Brim, Zeek.
* **Skills:** Analyzed live packet captures (PCAPs) to identify network-based attack signatures, unauthorized data exfiltration patterns, and Man-in-the-Middle (MITM) posture changes.

### 3. Endpoint Security Monitoring
* **Environments:** Windows (Sysmon, Event Viewer), Linux (Auditd, OSQuery).
* **Skills:** Audited system events to identify malicious process injections, persistence mechanisms, and living-off-the-land techniques.

### 4. Phishing & Threat Analysis
* **Methodologies:** Header analysis, parsing raw MIME tracking logs, and extracting suspicious payload signatures using safe sandbox execution workflows.

### 5. Defensive Framework Alignment
* **Frameworks:** MITRE ATT&CK Matrix, Cyber Kill Chain, Pyramid of Pain.
* **Skills:** Leveraged industry-standard models to map adversary behaviors, track attack lifecycles, and prioritize defensive engineering controls.
